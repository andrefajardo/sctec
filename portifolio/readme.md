# Portfólio Pessoal - Introdução à Programação Front-End e Back-End

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma landing page funcional para apresentação de um portfólio pessoal, elaborada como atividade prática extra do curso **Introdução à Programação Front-End e Back-End (IP 20h A)**.

A proposta da página é centralizar informações sobre minha formação, habilidades técnicas e comportamentais, bem como apresentar projetos desenvolvidos ao longo do curso ou criados para fins demonstrativos. O objetivo é utilizar esta aplicação como base inicial para construção de uma identidade profissional na área de tecnologia, permitindo futuras atualizações e ampliações conforme evolução da carreira.

## 🛠️ Estrutura do Projeto

O projeto contém os seguintes arquivos:

- `index.html` → Estrutura principal da página  
- `.\assets\` → Pasta contendo as 4 (quatro) imagens utilizadas  
- `.\styles\style.css` → Arquivo de estilização  
- `.\scripts\script.js` → Arquivo responsável pelas interações e comportamentos dinâmicos  
- `README.md` → Documentação do projeto  

---

## ▶️ Como Executar o Projeto

1. Baixar o arquivo compactado (.zip ou .rar).
2. Extrair os arquivos em uma pasta local.
3. Abrir o arquivo `index.html` em um navegador de sua preferência.

Não é necessária instalação de dependências externas.
