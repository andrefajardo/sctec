# Little Pet - Cuidado e Qualidade 🐾

## 📝 Descrição do Projeto
O **Little Pet** é uma landing page moderna e responsiva desenvolvida para um pet shop fictício. O objetivo do projeto é apresentar os serviços de banho, tosa, consultas veterinárias e venda de produtos de forma atraente e intuitiva para os tutores de animais de estimação. A página foi construída com foco na experiência do usuário (UX) e em uma identidade visual que transmite carinho, higiene e profissionalismo.

## 🚀 Status do Projeto
![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)
O projeto encontra-se em sua versão estável inicial, com todas as funcionalidades básicas de navegação e interface implementadas.

## ✨ Funcionalidades
- **Menu Responsivo:** Navegação adaptável para dispositivos móveis com uso de menu hambúrguer.
- **Seção Hero:** Chamada principal impactante com botões de ação (CTA).
- **Sobre Nós:** Informações institucionais e estatísticas de atendimento.
- **Serviços:** Cards interativos que apresentam as principais atividades do pet shop.
- **Formulário de Contato:** Interface para que os clientes enviem mensagens diretamente.
- **Scroll Suave:** Navegação interna entre as seções da página.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização avançada utilizando Variáveis (Custom Properties), Flexbox e Transições suaves.
- **JavaScript (Vanilla):** Lógica para interatividade do menu mobile.
- **Google Fonts:** Tipografias *Fredoka* e *Poppins* para uma leitura agradável e moderna.

## ⚙️ Como Executar o Projeto
### Pré-requisitos
Não há necessidade de instalar dependências externas ou compiladores, pois o projeto utiliza tecnologias web nativas. Você precisará apenas de:
1. Um navegador web moderno (Chrome, Firefox, Edge ou Safari).
2. Um editor de código (como VS Code) caso deseje realizar alterações.

### Passo a Passo
1. Faça o download do repositório ou clone-o usando o comando:
   ```bash
   git clone https://github.com/seu-usuario/little-pet.git
   ```
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` diretamente em seu navegador ou utilize a extensão **Live Server** do VS Code para visualizar em tempo real.

## 📐 Etapas de Desenvolvimento
O desenvolvimento deste projeto seguiu as seguintes etapas:
1. **Planejamento:** Definição da paleta de cores (Verde e Amarelo) e da estrutura da informação.
2. **Prototipagem:** Esboço das seções principais (Hero, Sobre, Serviços, Contato).
3. **Codificação HTML:** Implementação da estrutura semântica.
4. **Estilização CSS:** Aplicação de estilos globais, variáveis e layout responsivo.
5. **Interatividade JS:** Desenvolvimento do script para controle do menu em telas menores.
6. **Refinamento:** Ajuste de animações, sombras (box-shadow) e estados de hover nos botões e cards.
