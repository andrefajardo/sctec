## 📋 Sobre o SCTEC
O **SCTEC** é um programa estratégico do **Governo de Santa Catarina**, conduzido pela **SCTI (Secretaria de Estado da Ciência, Tecnologia e Inovação)** em parceria com o **SENAI/SC**. 

O programa visa impulsionar a inovação e o desenvolvimento tecnológico no estado, capacitando profissionais para o uso de **Inteligência Artificial** e preparando-os para construir ou aprimorar carreiras de alto impacto no setor de tecnologia.

🔗 [Saiba mais sobre o SCTEC](https://sctec.scti.sc.gov.br/)

---

## 🏗️ Estrutura do Repositório
Este repositório serve como centralizador dos projetos práticos desenvolvidos durante a trilha de aprendizado, divididos em três áreas principais:

- 💻 **Desenvolvimento de Software**: Construção de interfaces e lógica de sistemas.
- 📊 **Análise de Dados**: Transformação de dados brutos em insights valiosos.
- 🤖 **Inteligência Artificial**: Implementação de modelos e automações inteligentes.
